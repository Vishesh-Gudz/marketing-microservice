# convex/analytics

Query-time analytics over the canonical metric tables (Phase 6): exact aggregation, paired-sum KPIs,
periods and buckets, reporting-currency conversion, coverage-based data states, budgeted reads. No
providers, credentials or sync writes (ESLint-enforced). See [docs/analytics.md](../../docs/analytics.md)
and ADR 0007. Budget pacing is not part of Phase 6.
